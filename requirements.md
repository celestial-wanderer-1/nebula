# Requirements

- Modular and extensible fusion reactor design software

## UI

- Web based
- Design geometry
- Setup calculation
- View results
- Multiple projects
- Single project with multiple calculations
- Can be full design to simulation or each separate step
- Same or different geometry multiple calculation in a project

## Calculations

- Magnet design
- Magnetic field in a region from magnets or current carrying wires defined
- plasma equilibrium
- plasma stability
- time evolution (separate from plasma stability; plasma stability analysis can use methods that is suited to it)
- NVIDIA and AMD GPU calculations; no host side calculations
- Multiple nodes and GPUs support
